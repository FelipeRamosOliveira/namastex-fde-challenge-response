# ADR 0007: LLM gratuito como intérprete, nunca como decisor

- Status: aceito (29/09/2026)

## Contexto
O extrator por regras é previsível, mas não entende texto livre ("onix 21", "o top", "semana que vem"). Requisito: LLM com endpoint gratuito, custo controlado, sem PII e sem valores inventados.

## Decisão
- Provedores: Groq `openai/gpt-oss-20b` (structured outputs estrito, cerca de 1.000 tokens/s, `reasoning_effort: low`) e OpenRouter como reserva. Troca de provedor em erro, 429, timeout ou JSON inválido. Se o modelo recusar o schema estrito (400), tenta o modo JSON simples.
- O LLM faz duas coisas só:
  1. **Extrair** dados e intenções num JSON com schema. Cada campo é validado: idade e ano precisam aparecer no texto (ano aceita a forma abreviada), faixas plausíveis, CEP só se for token presente na mensagem, plano só dos 3 ids, data até 1 ano à frente. O que o LLM não trouxe e a regra achou, vale a regra. Intenções de segurança (humano, fora de escopo, mídia) são a união LLM + regras.
  2. **Redigir uma frase-ponte** quando o lead pergunta algo ou sai do fluxo. A frase é descartada se tiver dígito, R$, PII, token, promessa comercial ou mais de 180 caracteres. A resposta do fluxo (perguntas, confirmação, cotação) continua vindo dos templates.
- O LLM não escolhe o próximo passo, não chama ferramentas e não escreve valores.
- Defesa em profundidade: o `LLMClient` recusa enviar qualquer mensagem com PII detectável (`PiiBloqueada`).
- Injeção de prompt: o texto do lead vai delimitado e o sistema declara que ele é dado; como o LLM não decide nada, uma injeção bem-sucedida no máximo muda uma frase-ponte, que ainda passa pelos filtros.
- Cache exato (KVStore/Redis, 7 dias) por provedor, modelo, prompt versionado e mensagens.
- Qualquer falha do LLM cai no extrator por regras: o atendimento não para.

## Consequências
- Sem chave de LLM, o agente funciona igual à etapa 3.
- O ambiente da IA não alcança o Groq (política de rede): testes usam um Groq falso; o teste ao vivo (`uv run pytest -m llm tests/live`) e `scripts/smoke_llm.py` rodam na máquina do Felipe.
